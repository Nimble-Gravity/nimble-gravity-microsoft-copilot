Meet Analyst

Analyst is Researcher's quantitative sibling: a reasoning agent that takes your data files, thinks through the problem step by step, and writes and runs real Python — with the code on screen while it works. Where Researcher hands you a cited report, Analyst hands you computed answers, statistics, forecasts, and charts. This lesson is the spec sheet before you put it on finance data.

The Analyst Agent & Capstone · ~12 min read
01 — What it is

A data analyst that shows its work

Generally available since June 2025, Analyst is an advanced data-analysis agent built for exactly the questions a chat answer can't be trusted with: computation across files, statistics, and forecasting. It reasons in chain-of-thought, revising its approach over as many steps as the problem needs — and it does the math in code you can watch.

Chain-of-thought that iterates

Analyst plans an approach, tries it, inspects the result, and refines — as many steps as it takes. Give it a messy question and you'll see it restate the problem, probe the data's shape, and adjust its method mid-run, like an analyst working a workpaper.

It writes and runs Python

The computation isn't a language model estimating numbers — Analyst writes Python and executes it, with the code visible in real time. That pane is your audit trail: you can read exactly what was filtered, grouped, and summed before you trust a figure.

How you invoke it

Open the Agents list in the Microsoft 365 Copilot app and pick Analyst. Attach the files you want analyzed, or reference files already in your OneDrive or SharePoint through Graph — same grounding rules as everything else in this workshop.

🧠
What's under the hood — date-stamped

At GA (June 2025) Analyst ran on OpenAI's o3-mini reasoning model, tuned for advanced data analysis. The underlying model may have been upgraded since — treat the model name as a dated fact, not a permanent one. What hasn't changed is the design: reasoning first, then executable Python you can inspect.

02 — Where it sits

Analyst vs Copilot in Excel

You met Copilot in Excel in Module 2, and it also runs Python. The two overlap less than they sound like they do — the split is where the work happens and how many files are on the table.

Copilot in Excel

Edits the workbook you have open

Native, in-grid work on one open workbook: formulas, transformations, Python in the grid — with every Copilot edit attributed in Show Changes. When the deliverable is the workbook and you need cell-level auditability, this is the tool.

Use when: the answer belongs inside this spreadsheet.
Analyst

Reasons across multiple files

A chat-side agent that takes several files at once and does the heavier quantitative lifting — trend analysis, statistics, forecasting — outputting analysis, tables, and visuals. It does not edit your workbooks; it hands you findings to carry back into them.

Use when: the answer lives across files, or needs statistics and forecasts.
🧾
A sibling worth knowing: the Finance agent

The Agent Store also carries a role-based Finance agent (GA October 2025) built for Excel-based reconciliation and variance analysis with AI summaries — a narrower, close-desk specialist alongside the general-purpose Analyst. Worth a look once this module's habits are in place.

03 — Operating facts

The spec sheet, before you brief it

Three facts shape how you'll use Analyst day to day — what it eats, what it costs from your monthly budget, and where your verification lives.

01
Feeds on tabular files — plural
XLSX, CSV, and common data formats, and multiple files in one run — attached directly or referenced from your Graph files. A P&L extract plus a commission statement plus a rec ledger, analyzed together, is the normal case, not the edge case.
02
Shares the 25-query pool
Analyst and Researcher draw from one budget: 25 combined queries per user per month, resetting on the 1st (Microsoft's FAQ, updated March 2026). Every run should be a mission with a named deliverable — Lesson 3 turns that into a spending rule.
03
The Python pane is the review
Watch the code as it runs. Did it filter the months you meant? Sum the column you meant? Reading the Python is how a finance professional verifies method, not just output — Lesson 2 makes it a habit.
