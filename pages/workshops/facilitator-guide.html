Facilitator Guide

The minute-by-minute spine for the 2-hour Brown & Brown finance session: per-module beats, demo prompts, the planted findings in the synthetic data, and the recoveries when something stalls. Attendees don't need this page; nothing breaks if they read it — except the fun of the games, whose answer keys live in the two app READMEs, not here.

One session · 2 hours · 4 modules
00 — Ground rules

How the session runs

Two hours is tight for four modules. The design absorbs that in three ways: depth lives on the lesson pages (teach the beats, not the pages), every lab runs on pre-staged synthetic data, and the one long-running thing — Researcher — is kicked off at 0:25 so it lands by 1:05.

01
Day-before checklist
Verify in the B&B tenant: Researcher + Analyst visible in Agents; scheduled prompts on; Excel Copilot Python available; which model pickers show. Commission your own spare Project Lighthouse Researcher run the afternoon before — it's the fallback for anyone whose run fails. Test both games locally (./serve), and skim both app READMEs for the answer keys.
02
Timing discipline
The agenda times on the hubs are the contract: 0:10 M1 · 0:35 M2 · 1:00 break · 1:05 M3 · 1:30 M4 · 1:52 debrief. If a lab runs hot, cut the discussion beat, never the hands-on. The 0:25 Researcher kickoff is the one beat you protect at all costs.
03
The verify drumbeat
Every module ends on the same note: Copilot drafts, the teammate whose name is on it verifies and owns it. Say it four times, once per module — it's the culture you're actually installing.
0:10–0:35

Module 1 · Foundations & Copilot Chat

Goal: everyone prompting in four elements with a named source and Work IQ on, and every laptop with a Researcher run in flight by 0:35.

0:10–0:25 · Teach

Landscape, then the framework

Open the Module 1 deck. The one live demo that matters: ask the same question — "what drove our June variances?" — with no source named (generic, ungrounded essay), then again with Work IQ on and /profit-center-pnl.csv named explicitly (real answer, citation visible). Open the citation on screen — "before we read the answer, where did it come from?" That contrast carries the whole module. Then the four elements, fast, using the before/after in Lesson 2.

Say the data rules out loud: permissions are the boundary; no training on our data; agent sessions aren't e-discoverable by default — save outputs to files.
0:25–0:35 · Lab

Sprint, then commission

The lab page has all three prompts with copy buttons. At 0:30 sharp, everyone opens Agents → Researcher and pastes the Lighthouse mission brief; walk one clarifying-question exchange on screen ("work files and web, US market, finance audience"), then leave the runs cooking. Circulate: the usual blockers are Work IQ left off and lab files not yet indexed.

If someone's OneDrive hasn't indexed the files, have them attach the CSV directly — same result, no drama.
0:35–1:00

Module 2 · Copilot in the Apps

Goal: the room sees Excel Copilot plan, execute, and attribute a real analysis — then reproduces a mini close package. Everything runs on profit-center-pnl.csv, opened in desktop Excel from pre-work.

Excel demo prompt — run at 0:37, narrate the plan before approving 
Build a June 2026 budget-vs-actual variance table by profit center: total revenue and total expense variance, sorted by largest unfavorable. Then flag any profit center where the same account is unfavorable in at least 4 of the 6 months, and chart the top five June variances.
Narrate three things

The plan Copilot shows before acting, the Python it invokes for the multi-month scan, and afterward the Show Changes pane — "every cell it touched, attributed." That's the auditability story a controllership audience needs to see once to believe.

The planted finding

The 4-of-6-months flag should surface PC-402 Manhattan Retail — compensation ~9% over budget every month (~$651k for H1). If the room finds it, they've experienced the whole point: Copilot surfaced in seconds what a manual scan buries.

0:47 quick hits · 0:53 circuit

Quick hits from the Module 2 deck: Outlook triage, Teams recap, Narrative Builder — 90 seconds each, screenshots not live. Then the lab: Excel table → Word commentary paragraph. Close by pointing at the Variance Vault take-home; codes and derivations are in escape-room/README.md.

1:05–1:30 · after the break

Module 3 · The Researcher Agent

Goal: every table reviews a real Researcher report like a reviewer — citations spot-checked, gaps named — and leaves knowing what they'd commission next.

1:05–1:15 · Reports come home

Expect a spread — use it

Some runs will be done, some mid-flight, a few failed. That variance IS the lesson — complex runs take 10–45 minutes, which is why advanced users commission early. Pair unfinished runs with finished neighbors; project your spare run if needed. Walk the review pass from Lesson 11: four questions answered? three citations spot-checked? work-sourced vs web-sourced separated?

The Lighthouse report should flag contingent-dependence (15.5% of revenue), Gulfstream concentration (38%), and the uncapped earn-out. If a report missed one, that's your follow-up-question demo.
1:15–1:30 · Craft + the desk

Briefing craft, then real missions

Teach briefing craft off the room's own runs: whose clarifying answers were specific, whose report came back sharper. Then the discussion beat: each table names one real mission — deal research, carrier conditions, disclosure benchmarking — and one thing they would NOT send to Researcher (quick facts, single-workbook math). Remind: 25 queries a month shared with Analyst.

Cut the discussion, never the review pass, if time runs hot.
1:30–1:52

Module 4 · Analyst & The Close Room

Goal: one verified Analyst run per laptop, the decision framework installed, and teams briefed for the take-home capstone.

Analyst demo prompt — Agents → Analyst, attach carrier-commission-statements.csv 
For each carrier, compare the YTD loss ratio trend against its contingent profit-share threshold across Jan–Jun 2026. Which carriers' contingent accruals are at risk, and how much accrual is exposed? Chart loss ratio vs threshold by carrier, and state your method.
Narrate the Python pane

Analyst's signature move is reasoning you can audit: read the code out loud — "it's grouping by carrier, comparing against the threshold column." The planted finding: Gulfstream Property & Cas. ends June at 0.83 against a 0.60 threshold — the accrual collapse is visible in the June column. Old Colony (0.45) is the healthy contrast.

1:42 · Choosing your Copilot

Run the framework as rapid-fire call-outs — "MD&A background research?" (Researcher) — "formula fix in the open workbook?" (Excel Copilot) — "trend across four files?" (Analyst). End on the governance overlay: shared 25-query pool, save agent outputs to governed files.

1:48 · Brief the Close Room

Form teams of 3–4, show the four station names, point at the downloads on Lesson 16, and set the deadline (end of week). Answer key and derivation formulas: control-room/README.md. Monitor team progress live at the admin console during the take-home window.

🏁
1:52–2:00 · Debrief

Three beats: knowledge checks live at the end of each lab lesson (four quizzes → certificate on My Progress); take-home = Variance Vault, Close Room, and the one-week practice plan; then the 2-minute feedback before anyone stands up.

When it goes sideways

Recoveries, fast

01
No Researcher/Analyst in the Agents list
Admin hasn't enabled agents for that account, or the license isn't assigned. Pair them with a neighbor for the session and log the name for IT follow-up — don't debug licensing live.
02
Lab files won't reference with "/"
OneDrive hasn't indexed them yet. Attach the file directly in the chat instead — identical outcome. Prevent it next time by insisting on the pre-work upload a day ahead.
03
A Researcher run fails or stalls
Project your spare run from the day before. Failed runs still count against the 25-query pool, so don't have people blindly rerun — diagnose the brief first.
04
Excel Copilot won't run Python analysis
Rollout/region dependent. Fallback: run the same ask through Analyst with the CSV attached — and frame it with the decision framework: "multi-step analysis is Analyst's home turf anyway."
05
Someone burned their query pool
The 25/month Researcher+Analyst pool is per user. Pair them up for the rest of the session; it's also the perfect segue to the budget-discipline beat in Module 4.
06
Game unlock code rejected
Codes normalize to uppercase with whitespace stripped — the usual failure is a stale edit to the lab CSVs. Both READMEs carry the derivations; regenerate hashes with node tools/generate-hashes.mjs if data ever changes.
